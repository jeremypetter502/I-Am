## Summary

Deliver a Long Form (LF) I-AM output variant that expands compact segment identifiers and metric codes into full, human-readable names while preserving numeric parity with existing compact outputs. LF outputs must begin with the prefix `IAM/LF.0.1:` and order segments by aggregated module score (descending), with alphabetical tie-breaking.
