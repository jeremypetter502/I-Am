Aesthetic Preferences — Casual Module

Instructions
- Rate each item using this 1–5 scale:
  1 = Very inaccurate / Strongly disagree
  2 = Moderately inaccurate / Disagree
  3 = Neither accurate nor inaccurate / Neutral
  4 = Moderately accurate / Agree
  5 = Very accurate / Strongly agree
- For semantic-differential items (A — B) the left anchor = 1 and the right anchor = 5.
- Keep answers honest — there are no right/wrong answers.

PART D — Optional interactive tasks (use when you can show images)
- Pairwise A/B picks: show two thumbnails (A vs B) and ask which you prefer. Repeat across many pairs; use counts to estimate preference strength.
- Palette pick: show 3 palettes; ask to pick 1 or rank top 2.
- Font pick: show sample headings/body text in 3 fonts; pick preferred.

PART E — Open prompts (optional)
- List up to 3 websites, apps, or brands whose look you love (free text).
- In 3 words, describe the visual tone you prefer (e.g., "calm, modern, warm").

Scoring notes for implementers
- Use the same normalization for all 1–5 items: normalized = ((response - 1) / 4) * 100 → maps to 0–100.
- For semantic-differential items, mapping orientation matters. See the mapping spec file for exact inversion rules.
- Optional visual tasks (A/B, palette, fonts) provide higher-signal preferences; aggregate choices and convert to 0–100 (chosen_count/total * 100).

Privacy
- Treat responses as personal data. Do not reveal raw responses when personalizing outputs — summarize traits and preferences instead.

End of module.
