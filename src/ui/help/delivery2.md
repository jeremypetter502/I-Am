# Delivery v2

## Summary

Delivery v2 is a separate opt-in module that captures how you want information packaged and delivered. It focuses on six presentation preferences without overlapping with the Communication module.

## How to Answer

- Answer each statement on the same 1 to 5 scale used by the other questionnaires.
- Think about how you want an assistant to present work, not about your personality in general.
- Use your default preference, not a special-case situation.

## Key Metrics Produced

- `STR` - structure and explicit organization
- `DNS` - concise versus expanded explanation density
- `FRM` - formality and professional register
- `FMT` - strictness around requested output format
- `EMP` - emotional acknowledgement and reassurance
- `AUT` - initiative and proactive next steps

## Metric Meaning

These metrics describe delivery preferences only. They should shape packaging, tone register, and initiative level, while the Communication module remains the source of interpersonal style.

## How These Metrics Guide AI Behavior

The resulting profile can help an assistant decide whether to use structured sections, how concise to be, how formal the language should feel, how strictly to follow requested formats, how much emotional acknowledgement to include, and how proactive to be with suggestions.
